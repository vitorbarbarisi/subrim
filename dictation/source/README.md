# source/

Aqui vai o conteúdo de uma coleção salva pela aba **Coleções**: os PNGs e o `index.json`, soltos
nesta pasta (sem subpasta).

Origem: `warehouse/collections/<chave>_<formato>/`.

O conteúdo **não é versionado** de propósito — o `.gitignore` do repo já ignora `*.png` e `*.json`
em qualquer profundidade, e são dados gerados, por coleção, de vários MB. Este README existe só
para a pasta sobreviver no git.
